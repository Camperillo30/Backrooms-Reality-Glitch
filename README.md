# Backrooms: Reality Glitch

Este es la base del juego "Backrooms: Reality Glitch" creado en Godot 4.3.

## Estructura del Proyecto
- `scenes/`: Escenas principales (Menú, Jugador, Niveles).
- `scripts/`: Lógica en GDScript.
- `shaders/`: Efecto visual VHS/PSX.
- `prefabs/`: Módulos para la generación del laberinto.

## Controles
- **WASD**: Movimiento.
- **Shift**: Correr.
- **E**: Interactuar (Puerta de salida / Objetos).
- **I**: Inventario.
